Author: Gemini 4 Neon.  
Run all groups from the repository root:

```bash
bash agent_work/ch05/adversarial/run-all.sh
```

Output is written to `agent_work/ch05/adversarial/results.txt`. All scratch files are isolated under `_work/adv-ch05/`.

## Scope and Scaling Notes

- **Skipped outline bullets:** None in Chapter 5 mention a second SQLite version / newer driver release (every "Astra will try" bullet for 5.1–5.4 is covered, plus pin-enforcement checks in `INS-07`).
- **Iteration scaling:** `INS-06` is scaled to 5,000 deterministic seeded mutations (single bit-flips, truncations, multi-byte smashes, 32-bit integer smashes, and random buffers) across `walfile.Parse`, `Replay`, `ParseIndex`, `CompareBytes`, and `ParseShowwal`, and `CHK-01b` runs 40 concurrent commits racing all 4 checkpoint modes, keeping total runtime well under 1 minute on 4 cores / 7 GiB (far below the 10-minute target).
- **Portability:** All four Go attack groups are pure Go with no cgo and no Linux-only syscalls, so `GOOS=darwin go build ./...` compiles cleanly without build tags.
