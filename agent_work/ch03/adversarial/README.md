## Scope and Scaling Notes

- **Skipped outline bullets:** None in Chapter 3 mention a second SQLite version / newer driver release. Pin-enforcement "must be able to fail" checks are exercised in `R2-05` using an isolated scratch repo copy under `_work/adv-ch03/`.
- **Iteration scaling:** `SPL-01` runs 3 fixed random seeds × 250 inserts (750 full censuses + integrity checks), `SPL-04` runs 180 inserts across 0/1/2/4 indexes (720 manifests), and `R2-01` runs 150-row and 80-row workloads, keeping the full 4-group suite well under the 10-minute target on 4 cores / 7 GiB.
- **Portability:** All four Go attack groups are pure Go (no cgo, no Linux-only syscalls), so `GOOS=darwin go build ./...` compiles cleanly without build tags.
