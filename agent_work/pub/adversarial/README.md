# Publishing Chunk Adversarial Tests (`pub` — GitHub Pages site generator & repo sweep)

Author: Gemini 4 Neon.  
Run all groups from the repository root:

```bash
bash agent_work/pub/adversarial/run-all.sh
```

Output is written to `agent_work/pub/adversarial/results.txt`. All scratch files are isolated under `_work/adv-pub/`.

## Scope and Scaling Notes

- **Spec source:** `OUTLINE.md` §8 (rows A, B, C), `/root/briefs/sqlite-p2/chunkpub-build.md`, and `agent_work/pub/build-notes.md`.
- **Iteration scaling:** None needed. Every group runs against the live repository and isolated scratch git repositories in a few seconds total (well under the 10-minute target on 4 cores / 7 GiB). `LIVE-04` runs 6 full builds of the live repo across timezones, working directories, and parallel goroutines.
- **Cross-platform:** All four programs are pure Go with zero cgo and compile cleanly under `GOOS=darwin go build ./...`.
