Output is written to `agent_work/ch09/adversarial/results.txt`. All scratch files are isolated under `_work/adv-ch09/`.

## Scope and Scaling Notes

- **Iteration scaling:**
  - `CRASH-01` ("real `kill -9` at random times, thousands of iterations"): scaled to **1,200** real `SIGKILL` iterations (400 each at `OFF`, `NORMAL`, and `FULL`), parallelized across 4 worker goroutines. Total runtime for `crash-power-falsify` is ~1.5 minutes on 4 cores / 7 GiB.
  - `INT-01` ("seeded sweep over random byte offsets"): **500** distinct uniform random 1-bit flips across the 483,328-byte step-12 database, parallelized across 4 workers (~10 seconds).
  - `CAP-02a` / `CAP-02b`: 40 concurrent CLI `.backup` attempts per race (~5 seconds).
  - Full suite runtime is ~2.5 minutes, well under the 10-minute target.
- **Cross-platform builds:** All four Go programs compile cleanly under `GOOS=darwin GOARCH=arm64` and `GOOS=darwin GOARCH=amd64`. Attacks that require `strace` (`CRASH-02`, `CRASH-03`, `CRASH-06`, `SHIP-01a`, `SHIP-01b`) guard execution with `trace.Supported` and print a `LINUX-ONLY` note on non-Linux hosts.
